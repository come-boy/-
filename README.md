# 智招协同工作台

一个基于原生 `HTML + CSS + JavaScript` 实现的静态招生协同管理网页，适用于演示招生团队、成员、学校、线索与数据看板的统一管理流程。

## 功能特点

- 支持演示账号登录与按角色区分权限
- 支持管理招生团队、团队成员、学校资料、学生线索和对接关系
- 支持新增、编辑、删除、联系记录更新与状态跟进
- 支持在线索跟进页一键导入 Excel / CSV 表格并批量写入线索
- 支持数据看板、转化漏斗、成员效率和通知中心查看
- 支持桌面端与移动端自动切换布局，并根据屏幕宽度自适应展示
- 所有演示数据默认存储在浏览器 `localStorage` 中

## 本地打开

1. 直接在浏览器中打开 `index.html`。
2. 使用以下任一演示账号登录：
   - `superadmin` / `team2026`：超级管理员
   - `lead_green` / `team2026`：团队负责人
   - `member_lina` / `team2026`：招生老师
3. 登录后即可体验页面中的数据维护、通知查看和响应式布局效果。
