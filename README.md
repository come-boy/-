# 智招协同工作台

一个基于原生 `HTML + CSS + JavaScript` 的前端界面 + 轻量后端 API 的招生协同管理系统，用于管理团队、成员、学校、线索与数据看板，并提供正式的登录注册与账号审核能力。

## 功能特点

- 支持正式登录/注册（老师/家长/学生三类注册）
- 招生老师注册后需审核通过方可进入工作台
- 支持管理招生团队、团队成员、学校资料、学生线索和对接关系
- 支持新增、编辑、删除、联系记录更新与状态跟进
- 支持在线索跟进页一键导入 Excel / CSV 表格并批量写入线索
- 支持数据看板、转化漏斗、成员效率和通知中心查看
- 支持桌面端与移动端自动切换布局，并根据屏幕宽度自适应展示
- 业务数据默认仍存储在浏览器 `localStorage`（按账号隔离）；账号与审核信息存储在后端 JSON 数据文件中

## 本地启动

1. 安装依赖：
   - `npm install`
2. 在项目根目录创建 `.env`（可参考 `.env.example`），至少配置：
   - `SUPERADMIN_PASSWORD`
   - `SESSION_SECRET`
3. 启动：
   - `npm run dev`
4. 浏览器打开：
   - `http://localhost:5173/`
